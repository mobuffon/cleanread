# Railway Deployment Guide

## Prerequisites
1. GitHub account
2. Railway account (sign up at https://railway.app)
3. Push your code to GitHub

## Step 1: Push to GitHub

```bash
cd /Users/mobuffon/code/clean_read

# Initialize git if not already done
git init
git add .
git commit -m "Initial commit - CleanRead app"

# Create GitHub repo and push
gh repo create cleanread --private --source=. --push
# OR manually:
# Create repo on github.com, then:
git remote add origin https://github.com/YOUR_USERNAME/cleanread.git
git branch -M main
git push -u origin main
```

## Step 2: Deploy to Railway

### Option A: Using Railway CLI (Recommended)

```bash
# Install Railway CLI
npm install -g @railway/cli

# Login
railway login

# Initialize project
railway init

# Link to GitHub repo (auto-deploy on push)
railway link

# Add PostgreSQL
railway add --database postgres

# Add Redis
railway add --database redis

# Set environment variables
railway variables set DATALAB_API_KEY=YOUR_API_KEY_HERE
railway variables set SECRET_KEY=$(openssl rand -hex 32)
railway variables set FRONTEND_URL=https://your-app.railway.app

# Deploy
railway up

# Open in browser
railway open
```

### Option B: Using Railway Dashboard

1. Go to https://railway.app/new
2. Click "Deploy from GitHub repo"
3. Select your `cleanread` repository
4. Railway will auto-detect docker-compose.yml

5. **Add Services:**
   - Click "New" → "Database" → "Add PostgreSQL"
   - Click "New" → "Database" → "Add Redis"

6. **Set Environment Variables** (in each service):
   
   **Backend Service:**
   ```
   DATALAB_API_KEY=YOUR_KEY_HERE
   SECRET_KEY=generate-random-32-char-string
   DATABASE_URL=${{Postgres.DATABASE_URL}}
   REDIS_URL=${{Redis.REDIS_URL}}
   FRONTEND_URL=${{Frontend.RAILWAY_PUBLIC_DOMAIN}}
   POSTGRES_SERVER=${{Postgres.PGHOST}}
   POSTGRES_PORT=${{Postgres.PGPORT}}
   POSTGRES_USER=${{Postgres.PGUSER}}
   POSTGRES_PASSWORD=${{Postgres.PGPASSWORD}}
   POSTGRES_DB=${{Postgres.PGDATABASE}}
   ```

   **Frontend Service:**
   ```
   VITE_API_URL=https://${{Backend.RAILWAY_PUBLIC_DOMAIN}}
   ```

7. **Generate Domain:**
   - Click on Backend service → Settings → Generate Domain
   - Click on Frontend service → Settings → Generate Domain

8. **Enable Auto-Deploy:**
   - Settings → Deployments → Enable "Auto-Deploy"
   - Now every push to `main` branch triggers deployment

## Step 3: Verify Deployment

```bash
# Check backend health
curl https://your-backend.railway.app/api/v1/health

# Check frontend
open https://your-frontend.railway.app
```

## Step 4: Run Database Migrations

```bash
# Via Railway CLI
railway run alembic upgrade head

# OR via Railway dashboard
# Service → Settings → Command: alembic upgrade head
```

## Environment Variables Reference

### Required:
- `DATALAB_API_KEY` - Your DataLab API key
- `SECRET_KEY` - Random 32-char string for JWT
- `DATABASE_URL` - Auto-generated by Railway
- `REDIS_URL` - Auto-generated by Railway

### Optional:
- `MAX_UPLOAD_SIZE` - Default: 52428800 (50MB)
- `TRIAL_MAX_UPLOAD_SIZE` - Default: 5242880 (5MB)
- `USER_STORAGE_QUOTA` - Default: 52428800 (50MB)
- `FILE_RETENTION_DAYS` - Default: 14

## GitHub Auto-Deploy

Once connected:
1. Make changes locally
2. Commit and push to GitHub:
   ```bash
   git add .
   git commit -m "Update feature"
   git push origin main
   ```
3. Railway automatically deploys the new version
4. Check deployment status in Railway dashboard

## Troubleshooting

### Build Fails
```bash
# Check logs
railway logs

# Rebuild manually
railway up --detach
```

### Database Connection Issues
```bash
# Verify DATABASE_URL is set
railway variables

# Check PostgreSQL is running
railway ps
```

### Redis Connection Issues
```bash
# Verify REDIS_URL is set
railway variables

# Restart Redis
railway restart redis
```

## Cost Estimates

Railway charges based on usage:
- **Free Tier**: $5 credit/month
- **Developer Plan**: $5/month subscription + usage
- Estimated monthly cost: $8-15 for light usage

Usage breakdown:
- PostgreSQL: ~$2-3/month
- Redis: ~$1-2/month  
- Backend compute: ~$3-5/month
- Frontend static: ~$1/month

## Custom Domain (Optional)

1. Railway Dashboard → Service → Settings → Custom Domain
2. Add your domain (e.g., `app.yourdomain.com`)
3. Add CNAME record to your DNS:
   ```
   app.yourdomain.com → your-app.railway.app
   ```
4. SSL automatically provisioned
